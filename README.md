# Westview Bell System v2

This version uses the supplied real mechanical school-bell recording.

## Root files
Upload ALL of these files together at the root of the GitHub Pages repository:

- index.html
- style.css
- app.js
- lesson-bell.mp3
- lockdown-bell.mp3
- fire-bell.mp3

## Patterns

### Lesson
Choose 1, 2, 3 or 4 full bell bursts.
Each burst is followed by a selectable pause before the next burst.

### Lockdown
7 shorter bell pulses
→ 5.2 second pause
→ 7 shorter bell pulses

### Fire
Continuous mechanical bell.
The fire audio uses Web Audio looping with no programmed silence between loops.

## Important
This is a browser-based project/demo panel. It is not certified fire-alarm or emergency-alert equipment and should not replace a school's approved life-safety systems.
